# Kali Linux

## Use image in virt-manager
- Install `virt-manager`
- Download QEMU [image](https://www.kali.org/get-kali/#kali-virtual-machines)
- Follow these [steps](https://logos-red.com/blog/how-to-import-kali-linux-into-qemu-kvm/) for image import in `virt-manager`
- Fix NAT issues on Fedora [reddit](https://www.reddit.com/r/Fedora/comments/1ggvck8/comment/lxtxhvs/?utm_source=share&utm_medium=web3x&utm_name=web3xcss&utm_term=1)
- Enable `ssh` on kali &rarr; check `systemctl status ssh`

## Shortcuts
- `ctrl + alt` to unfocus VM session
